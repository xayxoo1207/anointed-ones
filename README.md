# ANOINTED ONES · 어노인티드 원즈

성경 속 영웅들이 우상과 괴수에 맞서는 뱀파이어 서바이버 스타일의 8비트 도트 게임입니다.

## 플레이
- GitHub Pages 주소를 휴대폰에서 연 뒤 **홈 화면에 추가**하면 앱처럼 설치되고, 한 번 연 뒤에는 오프라인에서도 실행됩니다.
  - iPhone: Safari → 공유 → 홈 화면에 추가
  - Android: Chrome → 메뉴 → 앱 설치 / 홈 화면에 추가
- 조작: 화면을 드래그해서 이동, 공격은 자동. PC는 WASD/방향키, ESC 일시정지, M 소리.

## 저장
해금한 스테이지와 영웅, 클리어 기록, 스테이지 클리어 시점의 '이어하기'가 기기(브라우저)에 저장됩니다.

## 파일
- `index.html` — 게임 전체 (단일 파일)
- `sw.js`, `manifest.webmanifest` — 오프라인 설치(PWA)
- `fonts/` — Black Han Sans, Do Hyeon, Press Start 2P (SIL Open Font License, 라이선스 파일 포함)

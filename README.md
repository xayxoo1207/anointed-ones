# ANOINTED ONES · 어노인티드 원즈

성경 속 영웅들이 우상과 괴수에 맞서는 **픽셀 로그라이크 게임**입니다.

15분 동안 몰려오는 적을 버티며 레벨업으로 무기와 패시브를 고르고, 미니보스가 떨어뜨리는 모루로 무기를 진화시켜 마지막에 등장하는 최종 보스를 물리치면 스테이지를 클리어합니다.

## 플레이
- GitHub Pages 주소를 열면 바로 플레이할 수 있고, **앱으로 설치**하면 한 번 연 뒤에는 오프라인에서도 실행됩니다.
  - iPhone: Safari → 공유 → 홈 화면에 추가
  - Android: Chrome → 메뉴 → 앱 설치 / 홈 화면에 추가
  - PC · Mac: Chrome 주소창 오른쪽의 설치 아이콘 → 설치
- 조작
  - 모바일: 화면을 드래그해서 이동, 공격은 자동
  - PC: WASD / 방향키로 이동, ESC · P 일시정지, M 소리 끄기
  - 메뉴: 방향키로 이동, Enter · Space로 선택, ESC로 뒤로
  - 레벨업: 카드를 한 번 눌러 고르고 한 번 더 눌러 확정 (숫자키 두 번), R로 제비 다시 뽑기

## 성장
- **무기 · 패시브**: 레벨업마다 선택합니다. 무기와 패시브는 각각 최대 6개까지 가질 수 있습니다.
- **무기 진화**: 무기 LV8 + 짝이 되는 패시브 + 미니보스의 모루. 일시정지 메뉴의 '무기 조합표'에서 확인할 수 있습니다.
- **스테이지 해금**: 스테이지를 클리어하면 새 영웅, 공용 무기(전신갑주 · 여리고의 나팔 · 베드로의 그물), 패시브, 주님의 은혜가 차례로 열립니다.
- **주님의 은혜**: 적을 처치하며 모은 기도로 영구 강화를 구입합니다. 모든 강화는 켜고 끌 수 있습니다.
- **엘리야의 물음**: 스테이지 중 등장하는 엘리야의 성경 퀴즈를 맞히면 축복을 받습니다.
- **멜기세덱의 축복**: 매 스테이지 맵 어딘가에 살렘 왕 멜기세덱이 나타납니다 (미니맵에 금잔 표시, 창 14:18). 기도를 드리면 패시브 하나로 축복하고 떠납니다. 패시브 6칸이 모두 찬 뒤에 받으면 7번째 패시브로 더해집니다.
- **미니맵**: 일시정지하면 주변 지도에서 나, 멜기세덱, 보스, 숨겨진 단서(???) 위치를 볼 수 있습니다.
- **컬렉션 I**: 영웅 · 무기 · 진화 무기 · 패시브를 모두 모으면 영웅 예수가 합류합니다.
- **컬렉션 II**: 예수 합류 이후의 수집 — 예수, 주님의 시험 보상, 숨겨진 길의 보상.

## 주님의 시험 모드
ST.16 아마겟돈을 클리어하면 열리는 하드 모드입니다.
- 적 이동 속도 +20%, 적 피해 +35%, 클리어 기도 2배
- 주님의 은혜를 더 높은 단계까지 강화할 수 있습니다.
- 주님의 은혜에 **한 몸의 지체**가 열립니다. 켜면 합류한 다른 영웅들의 고유 무기도 레벨업 화면에 나옵니다 (예수의 말씀 제외).
- 시험 보상: ST.01 독수리의 날개 · ST.04 첫 열매 · ST.08 갑절의 영감 · ST.12 열린 눈 · ST.16 의의 면류관
- 시험 모드로 클리어한 영웅에게는 '시험을 통과한 자' 표시가 붙습니다.
